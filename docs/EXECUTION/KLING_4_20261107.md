# Kling 4.0 rollout — 2026-11-07

## Outcome and acceptance

Add the reviewed `kling-4.0` native video contract without changing existing
models, inventing a partner price, running a paid generation, or enabling it for
partners. The model remains draft until an operator supplies all four partner
prices and records a successful live smoke.

Acceptance covers the exact native request shape, 3–30 second duration, 720p and
1080p tiers, text/reference ratios, 10 image and 5 video references (15 total),
no audio or frame references, optional generated audio, separate video-input
pricing, idempotent queue submission, confirmed-usage settlement, public RU/EN
reference material and a scoped repeatable database registration.

## Evidence and decisions

- Source reviewed: https://argolink.io/ru/models/kling-4.0 on 2026-11-07.
- Procurement: 0.1256/0.188 USD per billed second for 720p/1080p; with input
  video: 0.0754/0.113 USD per billed second.
- Partner prices remain an operator decision. No exchange-rate or markup policy
  was inferred from the procurement schedule.
- `video_input` is a distinct pricing mode because its procurement and partner
  price must be snapshotted independently from prompt/image-only generations.
- The existing provider adapter, durable queue, idempotency, polling, protected
  content delivery and usage settlement are reused. Provider identities and raw
  task IDs remain internal.
- The registration command creates the draft model and four provider capability
  rows only. It never creates prices, marks smoke successful, or enables access.

## Verification plan

- Focused contract/pricing/docs/registration tests.
- Native API → durable queue → mock provider → confirmed usage settlement and
  duplicate-idempotency regression.
- Existing contract, catalog, public-doc, adapter, billing and recovery suites.
- Full pytest and Ruff before PR; exact PR-head CI before merge.
- Live paid smoke and production enablement remain separate operator actions.

## Local verification

- 204 related contract, catalog, public-doc, adapter, billing and recovery tests
  passed; the focused Kling suite contains 9 passing tests.
- Full Windows-compatible coverage reached 1792 passed and 33 skipped. The remaining
  failures/errors exercise Unix-only media probe, symlink, shell, file-mode and atomic
  storage behavior (plus an unrelated FX-state assertion); exact Linux CI is the
  release gate.
- Full Ruff, `git diff --check`, and the registration dry-run pass. The dry-run
  reports draft status and explicitly confirms that it creates no partner prices or
  successful-smoke claim.
- No live provider request, production database write, partner-price decision or
  deployment was performed.
