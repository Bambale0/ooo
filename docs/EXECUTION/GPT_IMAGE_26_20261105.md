# GPT Image 2.6 — scoped integration (2026-11-05)

Reviewed source: https://argolink.io/api/catalog/v1/models?category=image&sort=provider&page_size=100
Catalog revision: `61d65a9a72ed9a1f`. The public `/v1/models` also lists both IDs.

- `gpt-image-2.6-flare`: fast generation and iteration.
- `gpt-image-2.6-sunburst`: detailed generation and reference editing.
- Both use `/v1/images/generations` and JSON/multipart `/v1/images/edits`.
- `size`: `auto` or pixel dimensions with a longest edge up to 2048. No 4K.
- `quality`: `auto`, `low`, `medium`, `high`, `xhigh`, `max`.
- 1–7 results; up to 16 references. The card publishes no reference byte cap;
  the gateway's normal total request limits still apply.
- `response_format`: `b64_json` or `url`. No `resolution`/`aspect_ratio` controls:
  request the desired dimensions through `size`.
- Procurement: USD 0.015 per returned image, at either 1K or 2K and any quality.

## Owner-approved pricing

The user's rule for these models is procurement plus 35%:

`partner_price_rub = ROUND_HALF_UP(0.015 * current_internal_rub_per_usdt * 1.35, 0.01)`

At an internal rate of 100 RUB/USDT this publishes RUB 2.03 per image.
The USD equivalent before RUB rounding is 0.02025. Rates are published once at
registration, not silently recalculated at generation time. Future FX changes
retain the existing admission economics checks and normal price publication flow.

## Registration after deployment

Run inside the configured application environment:

```sh
python -m app.catalog.gpt_image_26          # read-only price plan
python -m app.catalog.gpt_image_26 --apply  # one atomic, model-only transaction
```

The command creates only these two draft models, four price variants and four
ArgoLink capabilities. It reuses the normal price service for existing partner
snapshots and negotiated-rate protection; identical retries add no price history.
It preserves existing model status, smoke flags, balances and unrelated tariffs.
It never runs the global catalog importer: unrelated upstream drift is out of scope.

No production registration or paid supplier smoke has been performed by this code
change. After deployment, verify real generation and editing for both variants,
then update the truthful smoke flags and call the existing model enable endpoint.
Registration does not bypass that launch gate. Historical generations and their
accepted prices remain unchanged.
