# Telegram: PDF-справочник модели

Baseline: `5b436ea88ea3383bf1097b96dc207c64982a13af` (main). PR #187 — независимая редактура, не включается в этот feature branch.

## Состояние и критерии

- Существующий callback `docs` открывает только веб-руководство; middleware проверяет активного партнёра.
- `/v1/models` публикует только production-модели с контрактом в `MODELS`; restricted-модели исключены. PDF-каталог повторяет публичную выборку.
- Источники: `app/contracts/registry.py`, `app/api/{partner_reference,text_reference,native_video_reference}.py`. Примеры проходят локальный валидатор; непроверенные свойства не объявляются гарантированными. Цены не дублируются в PDF, используется ссылка на актуальные тарифы.
- Callback содержит UUID, сервер повторно проверяет доступность. Пагинация, фильтры, отдельная отправка документа без удаления каталога.
- PDF с встроенным кириллическим шрифтом, выделяемым текстом, переносами, несколькими страницами. Генерация вне event loop, ограниченный process-local cache; новый релиз сбрасывает cache. Без сетевых вызовов для генерации, БД-миграций и новых бизнес-параметров.
- Ошибки рендера и Telegram delivery видны в структурированных логах без ключей.

## Проверки

1. Добавить тесты для всех контрактов, безопасности данных, рендера и выбора модели.
2. Реализовать PDF и UI, зафиксировать зависимости/шрифты в build.
3. Проверить CI и production только при наличии подтверждённого доступа. Не считать незапущенные проверки успешными.
