# InfAI: аккаунт, каталог и цены по группам

Подтверждённое решение владельца от 03.10.2026: провайдер — `infai.cc`; розничные
тарифы совпадающих моделей остаются такими же, как в текущем каталоге Нейроныча
через ArgoLink. Сравнение с Kie отменено. Группы и коэффициенты InfAI учитываются
отдельно, а не сводятся к одной минимальной цене.

## Подключение

В приватном серверном окружении задаются `INFAI_SYSTEM_TOKEN` и `INFAI_USER_ID`.
Первое — системный токен аккаунта, второе — положительный числовой ID.
Токен хранится как `SecretStr` и скрывается форматтером логов.
Параметры нельзя добавлять в Git, URL, публичную документацию или Telegram.

Системный API требует `Authorization: Bearer <system token>` вместе с
`New-Api-User: <user ID>`. Токен генераций `sk-…` имеет другое назначение:
`/v1/models`, inference и `/api/usage/token/`. Системный токен туда не отправляется.
Наша интеграция не создаёт и не меняет токены InfAI.

## Доступные операции

`GET /api/v1/providers/infai/catalog` требует административный Bearer Нейроныча.
Партнёрский ключ не даёт доступа. Ответ содержит:

- безопасный срез аккаунта: остаток/расход в quota и USD, группа, число запросов;
- доступные группы, их коэффициенты и опубликованные статусы состояния;
- список моделей аккаунта и прайс, включая модели без известной цены;
- отдельные котировки для каждой доступной группы модели;
- основание коэффициента: точное имя, наиболее длинная маска или ставка группы;
- точные совпадения с локальным каталогом и текущие розничные ставки в RUB;
- время получения и явные признаки отсутствия изменения цен и маршрутизации.

В Telegram: «Администратор» → «InfAI: модели и цены» показывает сводку и обновление.
Для полного снимка на сервере:

```bash
python -m ops.infai_catalog --output-dir var/infai/2026-10-03
```

Каталог назначения должен быть новым. Создаются `catalog.json` и
`prices-by-group.csv` (UTF-8 BOM для Excel), доступ только владельцу на POSIX.
CSV содержит строку на каждую пару модель/группа и защищён от формул в названиях.
Экспорт содержит финансовые данные аккаунта; его следует хранить приватно.

## Контракты поставщика

Проверены чтением в живом API:

| Запрос | Назначение |
|---|---|
| `GET /api/user/self` | Аккаунт; локальная проекция исключает контакты, токены и настройки |
| `GET /api/user/models` | Доступные аккаунту идентификаторы моделей |
| `GET /api/user/self/groups` | Доступные группы, коэффициенты и опубликованное состояние |
| `GET /api/pricing_new` | Прайс с авторизацией аккаунта, коэффициенты и переопределения |
| `GET /api/status` | Публичный `quota_per_unit` для точного перевода quota в USD |

На момент проверки: 419 моделей аккаунта, 370 записей прайса, 49 моделей без цены,
85 групп, 1424 пары модель/группа. Это снимок, текущие значения запрашиваются заново.

## Расчёт и ограничения цен

Числа JSON читаются сразу в `Decimal`, вычисления имеют точность 50 знаков,
денежные значения административного ответа сериализуются строками.
Доллары InfAI не обозначаются автоматически как USDT и не конвертируются в RUB.

Коэффициент выбирается по правилам актуального интерфейса InfAI:

1. `group_model_ratio[group][model]`, если точное совпадение есть (включая ноль).
2. Самая длинная совпавшая маска с `*` на конце внутри этой группы.
3. `group_ratio[group]`.
4. Если коэффициент неизвестен — `null`, без предположения, что он равен единице.

Для обычного token billing (`quota_type=0`) базовые ставки за миллион токенов:
`input = 2 × model_ratio × group_ratio`, `output = input × completion_ratio`.
Cache/image multipliers применяются к input; audio ratios — непосредственно к группе.
Тарифные ступени и коэффициенты разрешений сохраняются в снимке. Эти базовые ставки
не являются готовой оценкой любого мультимодального/длинноконтекстного запроса.

Для media/credit billing `provider_base_price_usd = model_price × group_ratio` —
только базовая ставка. У видео, изображений, звука и специальных моделей есть
дополнительные коэффициенты и единицы: секунды, разрешение, кредиты, пиксели,
число изображений и другие параметры. Нельзя брать это поле как цену генерации
или потолок себестоимости. Специальная схема Gemini Omni также требует отдельного
контракта. Каждый ответ явно помечает необходимость оценки конкретного запроса.

Совпадение имени само по себе не доказывает эквивалентность API-контрактов.
Схожие названия Seedance, Veo и других семейств автоматически не объединяются.
Для точных совпадений возвращаются существующие `PartnerPrice`; никакие
`PartnerPrice`, персональные snapshots, capabilities, ledger или model gates
этим чтением не меняются. Для новых моделей стоит `retail_policy=requires_review`.

## Надёжность и границы

Запросы идут только на `https://infai.cc`; redirect не выполняется, секреты не
отправляются на сторонние сайты проверки ключей. Ответ ограничен 16 МиБ.
Повторяются только GET после сетевых сбоев, 429 и 5xx, не более трёх попыток;
длинный Retry-After возвращает временную недоступность вместо раннего повтора.
Ошибки авторизации, схемы, неверный аккаунт и нечисловые цены не превращаются
в пустой каталог или нулевую стоимость. Raw errors поставщика наружу не выдаются.

Интеграция предоставляет чтение и экспорт. Платная генерация, автоматический выбор
самой дешёвой группы, fallback и синхронизация закупочных ставок в финансовые таблицы
не включены: для них нужны проверенные request/response, billing и retry-контракты
конкретных моделей и успешные smoke gates проекта.
