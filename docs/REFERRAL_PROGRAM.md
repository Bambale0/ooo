# Партнёрская программа

## Правила

- Сумму пополнения API выбирает сам приглашённый пользователь; система создаёт
  в Lava.top инвойс ровно на введённую сумму.
- 7% начисляется от фактически подтверждённой суммы каждого такого пополнения.
- 20% от полной цены заказа на разработку начисляется один раз — только после
  подтверждённой оплаты и аванса 30%, и остатка 70%.
- Атрибуция первого валидного перехода бессрочная и не заменяется другой ссылкой.
- Саморефералы не атрибутируются.
- Начисление создаётся только после серверной проверки платежа у провайдера.

Партнёр видит ссылку, число приглашённых и чистую сумму начислений в Telegram-разделе
«Партнёрская программа». Суммы хранятся отдельным append-only ledger и не смешиваются
с API-балансом. Автоматический вывод вознаграждений в этот релиз не входит: способ и
реквизиты выплаты требуют отдельного подтверждённого бизнес-процесса.

## Идемпотентность и возвраты

Для каждого API-пополнения или полностью оплаченного проекта используется уникальный
ключ денежного события. Повторная доставка webhook возвращает прежний результат. При
подтверждённом частичном или полном возврате API-пополнения создаётся компенсирующая
реферальная запись, рассчитанная от исходной ставки 7%; старые записи не изменяются.

## Настройка

- `TELEGRAM_BOT_USERNAME` — username для готовой реферальной ссылки.
- существующие `LAVA_TOP_API_KEY`, `LAVA_TOP_OFFER_ID` и
  `LAVA_TOP_WEBHOOK_SECRET` используются для создания и подтверждения как
  API-пополнений, так и отдельных счетов по разработке.
